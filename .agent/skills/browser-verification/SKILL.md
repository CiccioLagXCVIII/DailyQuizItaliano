---
name: browser-verification
description: Verifica visuale e responsive di pagine web locali tramite screenshot e test headless.
---
Prima di considerare completata una pagina o componente UI:
1. Avvia o controlla il server dev locale (es. localhost:3000 o 5173).
2. Esegui uno script rapido con Playwright per scattare screenshot a 375px (iPhone) e 1440px (Desktop).
3. Verifica che non ci siano barre di scorrimento orizzontali anomale, testi illeggibili o contrasti cromatici insufficienti.
