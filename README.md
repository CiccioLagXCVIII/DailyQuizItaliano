# 🧩 Quizzettini - Daily Quiz Italiano

Benvenuti su **Quizzettini**, una dashboard minimale creata per raccogliere i migliori **Daily Quiz** in lingua italiana. 

L'obiettivo di questa pagina è offrire un punto di accesso rapido e organizzato ai quiz giornalieri.

## 🚀 Caratteristiche Principali

- 🎨 **Interfaccia Moderna:** Design con uno stile scuro (Dark Mode).
- 🕒 **Orologio in Tempo Reale:** Navbar con data e ora locale sempre aggiornata.
- 🔍 **Ricerca Rapida:** Filtra i quiz istantaneamente per nome tramite la barra di ricerca.
- ✅ **Sistema "Già Giocato":** Il sito tiene traccia dei quiz che hai già aperto. 
    - Il quiz viene sbarrato e appare una spunta verde.
    - Lo stato si resetta automaticamente **24 ore dopo il click**.
- 📱 **Totalmente Responsive:** Ottimizzato per l'uso su PC, Tablet e Smartphone.

## 🕹️ Quiz Inclusi

La lista include classici e novità, tra cui:
*   **Logica & Parole:** Wordle, Quordle, Parola Chiave, Frase Fortunata.
*   **Geografia & Mappe:** Travel, Angle, Guess The Angle.
*   **Musica & Media:** Songless, CronoNews, Gamedle.
*   **Cucina:** Food Guesser.
*   **Party Games:** Card Against Humanity.
*   ...e molti altri!

## 📦 Installazione Locale

Se vuoi scaricare il progetto sul tuo computer:
1. Clona il repository:
   ```bash
   git clone https://github.com/TUO-USERNAME/DailyQuizItaliano.git
   ```
2. Apri il file `index.html` nel tuo browser.

## 📝 Note Tecniche Sullo Stato Giocato
Il sistema di tracciamento non salva dati su server. Tutto viene memorizzato localmente nel tuo browser.  
Alcuni quiz (come *Higher Or Lower* o *Jeopardy*) sono esclusi dal sistema di sbarratura per permettere sessioni di gioco multiple senza vincoli temporali.
